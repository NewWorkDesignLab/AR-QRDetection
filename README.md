# Web AR Project

## Beschreibung
Dieses Projekt ist eine einfache Web-AR-Anwendung, die A-Frame, AR.js und Mediapipe für die Handverfolgung verwendet. Es bietet eine grundlegende Struktur für die Entwicklung von Augmented Reality-Erlebnissen im Web.

## Dateien und Verzeichnisse

- `src/index.html`: Einstiegspunkt der Anwendung mit grundlegender HTML-Struktur.
- `src/app.js`: Hauptlogik der Anwendung zur Initialisierung der AR-Umgebung.
- `src/styles/main.css`: CSS-Stile für das Layout und Design der Benutzeroberfläche.
- `src/components/ar-scene.js`: Funktion zur Erstellung einer AR-Szene mit A-Frame.
- `src/components/hand-tracking.js`: Funktion zur Implementierung der Handverfolgung mit Mediapipe.
- `src/assets/models`: Verzeichnis für 3D-Modelle, die in der AR-Anwendung verwendet werden.
- `package.json`: Konfigurationsdatei für npm mit Abhängigkeiten und Skripten.

## Installation

1. Klonen Sie das Repository:
   ```
   git clone <repository-url>
   ```

2. Navigieren Sie in das Projektverzeichnis:
   ```
   cd web-ar-project
   ```

3. Installieren Sie die Abhängigkeiten:
   ```
   npm install
   ```

## Nutzung

Um die Anwendung zu starten, öffnen Sie die `index.html`-Datei in einem Webbrowser, der Web-AR unterstützt. Stellen Sie sicher, dass Sie Zugriff auf eine Kamera haben, um die AR-Funktionen nutzen zu können.
